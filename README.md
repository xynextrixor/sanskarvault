## 🌟 What is SanskarVault?

**SanskarVault** is a modern, all-in-one study platform built specifically for engineering students. No more Googling for PYQs at 2 AM or spending hours making notes — SanskarVault gives you everything you need, right where you need it.

> 💡 *"The vault every BTech student wishes they had on Day 1."*

---

## ✨ Features

| Feature | Description |
|---|---|
| 📄 **Previous Year Papers** | Semester-wise PYQs for all branches — organized, searchable, one-click access |
| 🤖 **AI-Generated Notes** | Smart, concise notes powered by AI so you study smarter, not longer |
| 💻 **Coding Resources** | Curated programming material aligned with your BTech syllabus |
| 🗂️ **Semester Materials** | Subject-wise study material for every semester |
| 🎯 **Exam Prep Tools** | Smart tools to help you prepare strategically, not randomly |
| 🔍 **Instant Search** | Find any paper, topic, or resource in seconds |

## 🚀 Getting Started

### Prerequisites
- Node.js `v18+`
- npm or yarn

### Run Locally

```bash
# 1. Clone the repository
git clone https://github.com/yourusername/sanskarvault
cd sanskarvault

# 2. Install dependencies
npm install

# 3. Set up environment variables
cp .env.example .env.local
# → Add your GEMINI_API_KEY in .env.local

# 4. Start the dev server
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) and you're good to go 🎉
